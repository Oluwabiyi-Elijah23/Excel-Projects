# 📊 Excel Data Analysis Projects

## 📌 Overview

This repository contains a collection of **data analysis projects completed using Microsoft Excel**.

The projects demonstrate practical applications of Excel for **data cleaning, data transformation, analysis, data visualization, and dashboard development**, with each project focusing on transforming raw data into meaningful insights.

Each project is organized in its own folder and includes a detailed **README file** documenting the dataset, analytical process, techniques used, dashboard development, and key insights.
